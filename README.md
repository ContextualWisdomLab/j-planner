# J플래너

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/ContextualWisdomLab/j-planner)

J플래너는 로그인 없이 여행 일정, 지도 경로, 예약 서류와 캘린더를 브라우저 안에 보관하는 개인 여행 플래너입니다.

현재 제품은 `gh-pages` 브랜치의 단일 정적 웹 앱으로 제공됩니다. 날짜별 일정, 좌표 기반 지도·경로 보기, 일정별 예약 서류 보관, 앱 내 알림 등 여행 중 필요한 정보를 한곳에서 다룰 수 있습니다.

## 사용하기

GitHub Pages에서 바로 실행합니다:

https://contextualwisdomlab.github.io/j-planner/

별도 계정이나 서버 설정 없이 브라우저에서 사용할 수 있습니다. 저장된 여행 데이터의 보관·백업이 중요하다면 브라우저 데이터 정리 전에 필요한 정보를 별도로 보관하세요.

## 저장소 구조

- `index.html` — 배포되는 J플래너 정적 웹 앱
- `README.md` — 제품 및 저장소 안내

제품 동작과 현재 UI는 배포된 GitHub Pages와 `index.html`이 기준입니다.
