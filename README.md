# J플래너

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/ContextualWisdomLab/j-planner)

**여행 일정, 지도 경로, 예약 자료와 캘린더를 한 브라우저에서 관리하는 개인 여행 플래너.**

J플래너는 계정이나 별도 서버 없이 바로 사용할 수 있는 정적 웹 앱입니다. 여행별 일정과 위치를 정리하고, 예약 관련 자료를 일정과 함께 보관하며, 필요한 일정을 캘린더로 내보낼 수 있습니다. 현재 제품은 `gh-pages` 브랜치의 단일 `index.html`이 곧 실행 가능한 애플리케이션입니다.

## 바로 사용하기

현재 배포된 앱을 GitHub Pages에서 엽니다:

https://contextualwisdomlab.github.io/j-planner/

설치나 로그인은 필요하지 않습니다. 새 여행을 만들고 날짜별 일정을 추가한 뒤 장소 좌표를 넣으면 지도에서 동선을 확인할 수 있습니다. 필요한 예약 자료는 일정과 함께 보관하고, 여행 일정은 JSON 백업이나 ICS 캘린더 내보내기로 별도 보존할 수 있습니다.

## 무엇을 할 수 있나요?

| 필요 | J플래너가 제공하는 기능 |
| --- | --- |
| 여행 계획 | 여행별 일정과 날짜별 계획 관리 |
| 위치 확인 | 좌표 기반 지도와 여행 동선 확인 |
| 예약 자료 | 일정별 예약·참고 자료 보관 |
| 일정 전달 | ICS 캘린더 내보내기 |
| 백업 | JSON으로 여행 데이터 내보내기 |
| 현지 사용 | 설치형 백엔드 없이 브라우저에서 실행 |

## 데이터와 개인정보

J플래너의 여행 데이터는 브라우저 저장소를 중심으로 동작합니다. 별도 J플래너 계정이나 서버 데이터베이스를 제품 전제로 두지 않습니다.

이 구조는 간단하지만 브라우저 데이터 삭제, 사이트 저장공간 초기화, 기기 교체가 데이터 손실로 이어질 수 있습니다. 중요한 여행이라면 출발 전에 JSON 백업을 별도 보관하고, 필요한 일정은 ICS로 내보내세요.

지도 표시는 Leaflet을 사용하며 지도 타일 등 외부 지도 리소스는 해당 제공자의 네트워크·이용 조건을 따를 수 있습니다. 브라우저 로컬 저장이라는 설명이 모든 외부 네트워크 요청의 부재를 의미하지는 않습니다.

## 제품 경계

J플래너는 개인 여행 계획을 위한 브라우저 애플리케이션입니다. 항공사·숙박업체·결제사·지도 공급자의 예약 또는 상거래 시스템을 대체하지 않으며, 외부 예약의 성공 여부나 최신 운영 정보를 권위 있게 보증하지 않습니다.

현재 UI와 실행 동작의 기준은 보호된 기본 브랜치의 `index.html`과 실제 GitHub Pages 배포입니다. README는 그 동작을 설명하지만 구현되지 않은 서버 기능이나 계정 동기화를 별도 제품 기능으로 주장하지 않습니다.

## 구조

```text
Browser
  ├─ J플래너 UI / application logic
  ├─ browser-local travel data
  ├─ JSON backup / ICS export
  └─ Leaflet 1.9.4 map rendering
```

저장소는 의도적으로 작습니다.

- `index.html` — 배포되는 단일 파일 J플래너 웹 앱. 애플리케이션 CSS/JavaScript와 Leaflet 1.9.4가 인라인되어 있습니다.
- `README.md` — 사용자와 유지관리자를 위한 제품 안내입니다.
- `LICENSE` — J플래너의 원저작물에 적용되는 Apache License 2.0입니다.
- `THIRD_PARTY_NOTICES.md` — 인라인 반입된 Leaflet 등 제3자 코드의 별도 라이선스 고지입니다.

## 유지관리와 검증

이 저장소는 정적 Pages 앱이므로 README 변경만으로 제품 기능이 바뀌지는 않습니다. `index.html`을 변경할 때는 실제 브라우저에서 여행 생성, 일정 편집, 지도 표시, 백업/복원, ICS 내보내기와 저장소 유지 동작을 함께 검증해야 합니다. 사용자에게 보이는 기능 설명은 배포된 동작보다 앞서가면 안 됩니다.
